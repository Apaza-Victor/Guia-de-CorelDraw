Lección 08 · Avanzado

Exportación e impresión

Un diseño perfecto en pantalla puede fallar en la imprenta o pesar demasiado en la web si no conoces los formatos y ajustes correctos de salida.

8.1

Formatos de exportación y cuándo usarlos

FormatoÚsalo para
.CDRArchivo nativo editable; guarda todo el historial de capas y efectos
.PDF (imprenta)Entrega a imprenta: incrusta fuentes, sangrado y marcas de corte
.AI / .EPSCompatibilidad con Illustrator u otros flujos vectoriales
.SVGVectores para web: iconos, ilustraciones escalables ligeras
.PNGMapa de bits con fondo transparente para web o redes sociales
.JPGFotografías o composiciones sin transparencia; buena compresión
8.2

Preparar un archivo para imprenta

Sangrado (bleed)

Extiende los elementos que tocan el borde 2–3 mm más allá del tamaño final, para evitar líneas blancas al cortar. Se define en Diseño → Configuración del documento.

Modo de color

Confirma que el documento esté en CMYK antes de exportar. Revisa cada objeto en el cuadro Propiedades del objeto por si algún color quedó en RGB.

Fuentes

Convierte todo el texto a curvas (Ctrl+Q) antes de enviar el archivo, salvo que la imprenta pida lo contrario.

Vista previa de separaciones

Ventana → Cuadros de acoplamiento → Vista previa de separaciones, para ver cómo se dividirá el archivo en placas C, M, Y y K.

Cuidado Evita el "negro enriquecido" (una mezcla de CMY + K) en textos pequeños: en offset puede generar desalineación de placas y texto borroso. Para texto fino usa negro 100% K puro.
8.3

Exportar para web

Usa Archivo → Exportar (Ctrl+E) y elige PNG con fondo transparente para logotipos, o "Exportar para Web" para optimizar el peso comparando calidad vs. tamaño de archivo en tiempo real antes de guardar.

Ejercicio 8.1

Toma cualquier diseño que hayas hecho en lecciones anteriores. Configura un sangrado de 3 mm, convierte los textos a curvas, revisa la vista previa de separaciones y expórtalo como PDF listo para imprenta. Luego expórtalo también como PNG transparente para uso digital.
