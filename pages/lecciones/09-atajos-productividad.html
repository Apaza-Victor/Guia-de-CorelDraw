Lección 09

Atajos y productividad

La diferencia entre un usuario intermedio y uno experto casi nunca es "saber más herramientas": es dejar de tocar el mouse para todo. Memoriza estos atajos y multiplica tu velocidad.

9.2

Hábitos de un flujo de trabajo experto

Nombra tus capas y objetos

Un archivo con "Objeto 47" en vez de "Fondo azul" cuesta el doble de tiempo editar seis meses después.

Guarda versiones incrementales

Ctrl+Shift+S (Guardar como) con sufijos "_v1, _v2" evita perder trabajo si necesitas volver atrás.

Usa guías y la cuadrícula

Activa "Ajustar a guías" (Alt+Shift+Q en algunas versiones) para alinear con precisión sin medir manualmente.

Crea estilos reutilizables

El cuadro acoplable Estilos de objeto guarda combinaciones de relleno + contorno + tipografía para aplicar en un clic a futuros proyectos.

Ejercicio 9.1

Rehaz el Ejercicio 6.1 (la fila de círculos) pero esta vez sin tocar el mouse más que para dibujar las formas: usa solo atajos de teclado para duplicar, agrupar, alinear y guardar. Cronometra cuánto tardas y repítelo hasta bajar el tiempo un 30%.

9.3

Macros y VBA: automatiza lo repetitivo

CorelDRAW incluye un entorno de macros (VBA) con grabadora incluida. Graba una secuencia una vez y repítela después con un atajo o un botón, sin volver a hacerla a mano.

Grabar una macro

Herramientas → Macros → Grabar macro (Alt+Shift+R). Ejecuta tu tarea, detén la grabación y guarda la macro con un nombre claro.

Ejecutar y asignar

Herramientas → Macros → Ejecutar. Puedes asignar la macro a una combinación de teclas o colocarla como botón en una barra de herramientas.

Editor Visual Basic

Alt+F11 abre el editor VBA para retocar el código grabado o escribir macros personalizadas más sofisticadas.

Nivel Pro "Exportar PNG transparente a 300 ppp" o "aplicar el estilo de logotipo" son candidatos perfectos de macro: grábalos una vez y nunca más repitas la secuencia manualmente.
